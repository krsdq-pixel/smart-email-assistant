# Smart Email Assistant

Rock-solid multi-account inbox assistant built with React, TypeScript, Vite, Tailwind, and Capacitor.

## Features
- Charcoal / neon cyan / warm orange dark mode
- Full RTL Arabic UI support
- Multiple Google accounts with isolated state
- Resilient local persistence using Capacitor Preferences + localForage fallback
- Error boundaries for crash prevention
- Iron Shield for protecting critical emails from delete/archive actions
- Automated safe cleanup engine

## Getting started
1. npm install
2. npm run dev
3. Open the app in your browser on http://localhost:5173

## Mobile
1. npm run build
2. npx cap sync
